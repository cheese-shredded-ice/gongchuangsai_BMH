# 2026 年广东省工创大赛 · 智能物流搬运机器人 资料库

本仓库收录「智能物流搬运」赛项（MBH 项目）的完整参赛资料，涵盖 **结构设计、电控程序、视觉程序、任务命题文档、现场比赛经验** 五大板块。

> 项目主控：STM32F407（底层运动控制）＋ 树莓派（视觉识别），麦轮底盘 + 舵机机械臂 + CAN 总线电机。

## 四、视觉程序

视觉识别运行在 **树莓派**（OpenCV + pyzbar），通过 UART 与 STM32F407 通信，主要功能：

- **二维码识别**：下摄像头 + pyzbar，连续 3 帧确认任务码
- **物块颜色/位置识别**：HoughCircle 圆检测 + HSV 颜色识别
- **色环圆心定位**：粗/精定标（640×480 / 1920×1080 双分辨率）
- **边界线角度校正**：Canny + HoughLinesP 检测场地边界线

> ⚠️ 树莓派端 Python 源码（`zongchengxu20250801chusai.py` 等）**未收录在本仓库**（运行于树莓派上）。
> 完整的 **视觉通信协议、数据帧格式、各阶段视觉任务与返回值** 已详细记录在 [`全流程说明.md`](./全流程说明.md) 第三、四、五章节，可直接据此恢复视觉端程序。

## 六、现场比赛经验

现场照片与资料位于 [`图片/`](./图片/)：

| 文件 | 内容 |
|------|------|
| `现场.jpg` | 比赛现场全景 |

| `现场葫芦五兄弟.jpg`、`罪恶二维码板.jpg`、`自断一臂.jpg` | 现场记录（含场地道具、二维码板等） |

比赛关键经验与踩坑点集中在 [`全流程说明.md`](./全流程说明.md)：

- **系统架构**：STM32（CAN + PID + 麦轮 + 舵机）与树莓派（OpenCV + pyzbar）的串口分工
- **通信协议**：`0xFF + 9字节 ASCII + 0xFE` 数据帧，单字节命令触发视觉任务
- **完整任务流程**：扫码取任务 → 圆台取料 → 穿越 1700mm 通道 → 色环放置/取回 → 返回，共 9 个阶段
- **失败处理**：视觉未识别、颜色不匹配、超时等场景的应对策略
- **注意事项**：`jixie_reset()` 末尾 `while(1){}` 会导致第二轮不运行等已知问题
